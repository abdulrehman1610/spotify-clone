# Spotify Clone 🎵

A minimalist music player interface inspired by Spotify.

## 🚀 Features
* **Modern UI:** Clean, responsive design using CSS Flexbox and Grid.
* **Music Player:** Interactive player controls (Play/Pause/Skip).
* **Dynamic Cards:** Organized song layouts with hover effects.

## 🛠️ Tech Stack
* **HTML5** - Structure and semantic markup.
* **CSS3** - Custom styling and layout.
* **JavaScript** - Audio logic and UI interactivity.
